# 옵시디언 캐릭터 모델링 제2의 뇌 — 최종 소스 v2.0

이 문서는 증분 동기화 구조를 포함한 최신 단일 기준 문서다.
이전 프로젝트 소스와 충돌하면 이 문서를 우선한다.

## 최종 목표

```text
매주 학생별 옴니버스 수업
→ 검증된 강의 기록
→ 학생별 진행 이력
→ 공용 개념
→ 캐릭터 제작 단계별 워크플로우
→ AI가 근거와 타임스탬프를 제시하는 제2의 뇌
```

## 핵심 구조 변경

매주 전체 Obsidian 저장소 또는 캐릭터 모델링 폴더 전체를 보내지 않는다.

사용자는 저장소 루트의 다음 파일만 보낸다.

```text
00_매주_ChatGPT에_보낼_AI동기화팩.zip
```

함께 보내는 이번 주 자료:

```text
- 이번 주 SBV/SRT/VTT
- 이번 주 NotebookLM 분석본
- YouTube URL
- 강의 날짜·강사·과정명
- 선택 이미지
```

## AI 동기화팩의 역할

동기화팩은 현재 지식베이스의 완전한 경량 스냅샷이다.

포함:

```text
- AI 허브
- 과정 목차
- 강의 인덱스
- 학생 사례 전체
- 개념 전체
- 캐릭터 워크플로우 전체
- 지식베이스 시스템 규칙
- 모든 강의의 강의목차·북마크·최종노트
- 현재 SKILL.md와 manifest.json
- 파일 목록과 SHA-256 manifest
```

제외:

```text
- 모든 과거 원문전사
- 자막 원본
- 이미지
- NotebookLM 원본
- .obsidian
- 검사·임시 파일
```

과거 원문이 필요한 경우 강의 인덱스를 보고 해당 날짜의
`01_원문전사.md`만 추가 요청한다.

## 매주 처리

```text
AI 동기화팩 검증
→ 이번 주 자막·NotebookLM 검증
→ 학생 세션 분리
→ 기존 학생·개념·워크플로우 병합
→ 새 강의 생성
→ 강의 인덱스 갱신
→ AI 동기화팩 완전 재생성
→ 옵시디언_주간업데이트.zip 생성
```

## 사용자 결과

AI는 다음 파일 하나만 제공한다.

```text
옵시디언_주간업데이트.zip
```

사용자가 이 ZIP을 저장소에 덮어씌우면:

```text
- 새 강의 설치
- 학생·개념·워크플로우 갱신
- AI 허브·목차·강의 인덱스 갱신
- 다음 주에 보낼 AI 동기화팩 교체
```

가 한 번에 끝난다.

## 쓰기 안전

- 동기화팩이 없거나 손상되면 추측 병합 금지
- 기존 사용자 문장 보존
- 안정적 ID 유지
- 불확실한 학생 이름 자동 병합 금지
- 같은 개념 중복 생성 금지
- 정확한 과거 발언이 필요하면 원문 요청
- 동기화팩은 매번 부분 수정이 아니라 완전 재생성

## 현재 시드

- 강의: 1회
- 학생 사례: 6명
- 공용 개념: 8개

- 현재 동기화팩: `00_매주_ChatGPT에_보낼_AI동기화팩.zip`
- 공식 지식베이스 폴더명: `캐릭터_모델링`
- 독립 검사 명령: `/obsidian-lint`
- 소스 중복 방지: `소스 인덱스.md`
- 미확정 지식 추적: `지식 간극 및 검토 대기.md`
- 변경 추적: `병합 로그.md`


## 4.2 분리 원칙

이 프로젝트는 일반 동영상 강의용 `obsidian-lecture-pack`과 독립된다.
CG 지식베이스, 학생 이력, 동기화팩은 일반 강의 지식베이스와 자동 혼합하지 않는다.
CG 명령은 `/obsidian-cg` 또는 `/obsidianpack-cg`를 사용한다.
