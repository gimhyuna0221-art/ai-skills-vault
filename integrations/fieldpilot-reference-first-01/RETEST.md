# Reference-first-01 — focused retest, NOT_RUN

Baseline: report-actionability-01 @ 3e6a66b6c5f44eb84b49509d899114f0e0587e14.
Purpose: references before conclusions, with useful options and limited user burden.
Keep the previous smartwatch/earphone six-section cases unchanged. Do not coach
one arm with extra instructions. Compare the same host/model/access conditions in
fresh sessions; save raw answers, actual source reads, artifacts and user effort.

Additional controls, all NOT_RUN in an external model:
1. Adequate supplied report: reuse it, inspect scope, avoid redundant discovery.
2. Viral tool with gated output vs inspectable task-fit evidence: do not promote
   marketing to verified performance; unavailable quality is UNKNOWN.
3. Stale known report: refresh the affected metric, do not re-research everything.
4. Sources disagree on category/period: preserve distinction, no false average.
5. Supplied-source-only summary: no outside search or unsolicited strategy.
6. One-off repair product with general-AI overlap: compare usable completion and
   actual remaining work; do not apply recurrence/80%/prepayment kill thresholds.
7. New niche with no adequate report: lawful targeted evidence plus explicit gaps;
   do not invent a best service or return only a source-finding homework task.
8. Existing alternative demonstrably sufficient: allow reuse/HOLD; do not fabricate
   differentiation to favor FieldPilot or the owner's idea.

Judge sources AND final usefulness. Ask whether material claims were inspected,
why selected sources fit better, whether options/trade-offs are understandable,
and what the user must still do. Do not reward site count, tone, or brevity alone.
Reuse the existing report_actionability review rubric; source/permission failures
remain hard failures. Code/instruction tests are not these behavioral trials.

Release scope: no sale/listing/price promise, installed-host certification, latency
savings or universal '#1' claim follows from this patch. Test the intended sales
host first and state its capabilities/limitations in the eventual product listing.
