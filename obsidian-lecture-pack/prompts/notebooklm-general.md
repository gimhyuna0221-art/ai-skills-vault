# NotebookLM General Lecture Analysis Prompt — Compact v1.3

선택한 이번 강의 소스만 근거로 분석해줘.
다른 날짜 강의, 선택하지 않은 소스, 외부 지식을 섞지 마.

이 프롬프트는 학생별 피드백 수업이 아닌 일반 설명형·실습형·주제형·설교·튜토리얼용이다.
학생·수강생별 진도, 이전 피드백, 재등장 세션, 학생별 과제를 만들지 마.
여러 학생이 서로 다른 CG 제작 단계에서 순차적으로 피드백받는 수업은 이 분석을 중단하고 CG 옴니버스 전용 스킬을 사용해야 한다.
학생별 피드백이 없는 CG 튜토리얼은 일반 강의로 처리한다.

## 규칙

1. 확인되지 않은 정보는 추측하지 않는다.
2. 시간 정보가 있을 때만 사용하고 없으면 만들지 않는다.
3. 발췌 번호를 영상 시간으로 해석하지 않는다.
4. 각 시작·끝 앵커는 원문에 연속해서 존재하는 5~15어절을 그대로 적는다.
5. 앵커 하나에 서로 다른 시간 구간의 문장을 이어 붙이지 않는다.
6. 앵커는 시간 제목·구분선·다음 타임코드를 가로지르지 않는다.
7. 강사의 직접 설명, 사례·비유, 화면 자료, 분석 후보를 구분한다.
8. 강사가 말하지 않은 원인·예외·복구법·작업 순서를 만들지 않는다.
9. 화면에서만 확인 가능한 내용은 `화면 확인 필요`로 표시한다.
10. 전문용어·수치·도구명이 불확실하면 원문과 교정 후보를 함께 적는다.
11. 한 강의만으로 원칙이나 절차를 `standard`로 확정하지 않는다.
12. 내용이 없는 항목은 `확인되지 않음`으로 표시한다.
