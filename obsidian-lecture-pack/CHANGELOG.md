# Changelog

## 1.1.2 — 2026-08-02

### Changed

- `notebooklm-general.md`를 실제 NotebookLM 입력용 압축 프롬프트로 교체
- NotebookLM은 근거 추출, Obsidian Lecture Pack 스킬은 최종 구조화·패키징을 담당하도록 역할 분리
- 일반 강의 출력 구조를 17개 섹션에서 8개 핵심 섹션으로 축소

### Fixed

- 긴 프롬프트가 NotebookLM 채팅 입력창에 전부 들어가지 않는 문제 대응
- NotebookLM과 후속 스킬에 동일한 상세 산출물을 중복 요구하던 구조 제거


## 1.1.1 — 2026-08-02

### Added

- 일반 강의와 CG 학생별 옴니버스 피드백 수업의 프롬프트 라우팅 규칙 명시
- 학생이 없는 CG 튜토리얼은 일반 강의 프롬프트를 사용한다는 예외 규칙 추가
- 일반 강의와 CG 옴니버스 결과 구조의 혼입 여부 검사 추가

### Changed

- CG 특수 프롬프트 파일명을 `notebooklm-cg-omnibus-feedback.md`로 명확화
- 일반 강의는 `notebooklm-general.md`를 사용하도록 문서 구조 정리
- 프롬프트 선택 기준을 강의 분야보다 강의 형식 우선으로 정리

### Fixed

- `notebooklm-general.md`에 남아 있던 이전 파일명
  `notebooklm-cg-character.md` 참조를 새 파일명으로 수정
- 일반 강의에서 학생·진도·이전 피드백 필드가 생성될 수 있는 혼동 제거


## 1.1.0 — 2026-08-02

### Added

- `/옵시디언팩만들어줘` 호출어 추가
- YouTube `스크립트 표시`에서 시간 포함 자막을 가져오는 절차 추가
- `분:초`, `시:분:초`를 초 단위 링크로 변환하는 규칙 추가
- YouTube 시간 표시 스크립트 기반 클릭형 북마크 생성 규칙 추가
- 일반 강의·CG·웹소설 작법·신규 분야 프로필 선택 규칙 추가
- 사용자용 볼트와 AI 동기화·검사 자료를 분리하는 ZIP 구조 추가
- 종료 시각과 `종료 후보`를 구분하는 규칙 추가
- 입력 유형·시간 근거·프로필 혼입 여부 검사 추가

### Changed

- 입력 우선순위를 `SBV/SRT/VTT → YouTube 시간 스크립트 → 무시간 전사 → NotebookLM`으로 명시
- 공통 엔진과 분야별 프로필을 분리
- 일반 강의 결과에 CG 프로필 등 무관한 자료가 들어가지 않도록 변경
- 사용자용 Obsidian 폴더에는 강의·개념·워크플로우 노트만 포함하도록 변경
- NotebookLM 분석은 구조 후보로 사용하고 원문 앵커와 대조하도록 강화
- 한 강의만으로 `standard`를 부여하지 않는 검증 규칙 강화

### Fixed

- 개발용 `SKILL.md`, 도메인 프로필, 검사·설치 문서가 Obsidian 그래프에 노출되던 패키징 문제 수정
- 시간 없는 전사문에서 가짜 타임스탬프를 만들 수 있는 위험 차단
- YouTube 챕터 제목과 실제 발화를 혼합할 수 있는 문제에 대한 분리 규칙 추가

### Validation

- 일반 웹소설 작법 강의 1건으로 기본 생성 흐름 확인
- Obsidian 열기, 원문·최종노트·개념·워크플로우 생성 확인
- YouTube 시간 표시 스크립트 기반 클릭형 북마크는 재검증 필요
- 사용자용 팩과 내부 자료 분리도 재검증 필요

## 1.0.0 — 2026-07-31
