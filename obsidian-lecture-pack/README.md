# Obsidian Lecture Pack

강의 영상, YouTube 시간 표시 스크립트, 자막, NotebookLM 분석본을 근거로
원문·북마크·최종노트·개념·분야별 워크플로우가 연결된 Obsidian 강의팩을 생성합니다.

현재 버전: `1.1.2`  
현재 상태: `stable draft`

## 호출

```text
/obsidianpack
```

```text
/옵시디언팩만들어줘
```

또는:

```text
옵시디언 강의팩 만들어줘.
```

## 지원 입력

- 강의명·날짜·강사명·분야
- YouTube URL
- SBV/SRT/VTT 자막
- YouTube `스크립트 표시`에서 복사한 시간 표시 스크립트
- 시간 없는 TXT 전사문
- NotebookLM 분석본
- 화면 캡처와 사용자 메모
- 누적 병합용 AI 동기화팩

## 시간 정보 우선순위

1. SBV/SRT/VTT
2. YouTube 시간 표시 스크립트
3. 시간 없는 전사문
4. NotebookLM 분석본

시간 정보가 있으면 검증된 시작 시각으로 클릭형 YouTube 북마크를 만듭니다.

시간 정보가 없으면 시간을 추측하지 않고 원문 검색용 앵커만 만듭니다.

## YouTube 스크립트 가져오기

1. YouTube 영상을 엽니다.
2. 영상 설명의 `더보기`를 누릅니다.
3. `스크립트 표시`를 누릅니다.
4. 시간 표시가 보이는 상태로 둡니다.
5. 스크립트 전체를 복사합니다.
6. YouTube URL과 함께 제공합니다.

YouTube 자동 생성 스크립트에는 오인식이 있을 수 있으므로
원문은 보존하고 교정 후보를 별도로 기록합니다.

## 프롬프트 라우팅

강의 분야보다 강의 형식을 먼저 판별합니다.

### 일반 강의 영상

다음 프롬프트를 사용합니다.

```text
prompts/notebooklm-general.md
```

적용 대상:

- 일반 설명형·실습형·주제형 YouTube 강의
- 웹소설 작법 강의
- 디자인·이론·도구 강의
- 학생별 피드백이 없는 CG 튜토리얼

분석 단위는 주제·챕터·개념·사례·절차·실습·복습입니다.
학생, 학생별 진도, 이전 피드백, 학생별 과제를 임의로 만들지 않습니다.

### CG 학생별 옴니버스 피드백 수업

다음 특수 프롬프트를 사용합니다.

```text
prompts/notebooklm-cg-omnibus-feedback.md
```

적용 대상은 현재 듣는 CG 수업처럼 여러 학생이 서로 다른 제작 단계에서
순서대로 피드백을 받는 옴니버스형 수업입니다.

분석 단위는 학생·작업물·현재 제작 단계·이전 피드백·수정 순서·다음 과제입니다.

CG 분야라는 이유만으로 이 특수 프롬프트를 사용하지 않습니다.
학생이 없는 CG 유튜브 튜토리얼은 일반 강의 프롬프트를 사용합니다.

## NotebookLM과 스킬의 역할 분리

NotebookLM에는 짧은 근거 추출 프롬프트를 사용합니다.

NotebookLM의 역할:

- 강의 구조와 주제 경계 추출
- 원문 앵커와 확인된 시간 추출
- 주장·근거·절차·개념 후보 정리
- 불확실성과 화면 확인 항목 표시

Obsidian Lecture Pack 스킬의 역할:

- 원문과 NotebookLM 분석 대조
- 클릭형 북마크 생성
- 최종노트·개념 노트·워크플로우 생성
- 내부 링크 검사
- 사용자용 볼트와 AI 동기화팩 분리
- ZIP 패키징

따라서 17개 이상의 최종 산출물 항목을 NotebookLM 채팅창에 모두 넣지 않습니다.


## 결과 ZIP 구조

```text
옵시디언_강의팩.zip
├─ 볼트에_복사/
│  └─ 분야명/
│     ├─ 00_AI허브.md
│     ├─ 00_과정목차.md
│     ├─ 강의/
│     ├─ 개념/
│     └─ 워크플로우/
├─ AI_동기화용/
│  └─ 00_매주_ChatGPT에_보낼_AI동기화팩.zip
├─ 검사자료/
└─ README.md
```

사용자는 `볼트에_복사/분야명/`만 Obsidian 볼트에 넣습니다.

`SKILL.md`, 도메인 프로필, 검사결과, 설치문서, 내부 시스템 규칙은
사용자용 볼트에 넣지 않습니다.

## 검증 현황

### 통과

- 일반 강의 자료로 강의팩 생성
- Obsidian에서 노트 열기
- 원문·최종노트·개념·워크플로우 생성
- 내부 링크 검사

### 재검증 필요

- YouTube 시간 표시 스크립트 기반 클릭형 북마크
- 사용자용 볼트와 내부 자료의 완전 분리
- 압축된 일반 강의 프롬프트가 NotebookLM 입력창에 정상 입력되는지 확인
- 일반 강의 프롬프트에서 학생 필드가 생성되지 않는지 확인
- CG 옴니버스 프롬프트에서 학생별 세션이 보존되는지 확인
- 서로 다른 실제 강의 3회 이상 반복 실행
- 처음 사용하는 사람이 README만 보고 실행 가능한지 확인

자세한 기준과 실행 기록은
[Validation Log](VALIDATION_LOG.md)에서 확인할 수 있습니다.

## 현재 알려진 한계

- YouTube 자동 자막의 전문용어·인명·작품명은 틀릴 수 있습니다.
- 화면에만 표시된 예문·설정값은 자막만으로 복원할 수 없습니다.
- 한 강의에서 추출한 원칙은 `standard`로 확정하지 않습니다.
- 기존 AI 동기화팩이 없으면 과거 지식과 병합했다고 주장하지 않습니다.
