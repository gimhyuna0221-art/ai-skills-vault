# Incident analysis and prevention — 2026-09-20

## Observed facts

The prior publication really exists: commit `2072f5559354ecb375a8680f9e6e8e02b834bb8a` added the skill and CI. Actions run `35455559208` recorded successful Ubuntu/Python 3.11 and Windows/Python 3.13 jobs. The assistant later denied remote-write capability without first inspecting the connected GitHub actions, and incorrectly retracted the earlier completion report. A subsequent connector read confirmed both the commit and CI. The new update was still local and not on main; these were two different states.

The local 1.1.0 draft also contained a concrete algorithm error: it indexed `subdivision_levels - step`, so increasing its supposed coarsening step selected finer rather than coarser arrays. Its selection could return full resolution as low-poly. It exported the companion without independent reload, shape/error, or actual-reduction checks. Its small example skipped low-poly, and the shown heavy attempts timed out during export. Compilation and that small example therefore did not validate the new behavior.

## Supported process causes

1. **Capability discovery was skipped.** Local shell/git limitations were incorrectly generalized to the connected GitHub service. No current permission error had been established for the denied operation.
2. **Evidence and task states were conflated.** An earlier completed commit, an uncommitted local draft, the current branch ref and CI for a particular SHA were not tracked separately.
3. **Validation did not cover the changed branch.** A skipped low-poly path and compilation check were used in a completion-style report; numeric output counts and low-poly reload checks were missing.
4. **Execution retries lacked a state-based decision.** The same timed-out export stage was repeatedly restarted instead of checking process/checkpoints and choosing an appropriate execution path.
5. **No durable acceptance gate was applied to reporting.** Conflicting assertions were made instead of checking the named commit/ref/run.

These are conclusions from visible actions, code and records. The internal model, hidden memory mechanisms, reasoning-level setting, backend timeout cause, or account configuration are not diagnosed here; the evidence does not establish them. A current container transport failure also does not imply a GitHub connector failure.

## Implemented prevention

- Root `AGENTS.md`: discover current connectors, read exact ref/files, distinguish local from remote capability, preserve source/license/scope, reconcile concurrent changes, fast-forward only, then read back the remote ref/blobs.
- Exact-SHA CI gate: inspect current push-triggered workflow jobs/steps. Do not reuse old green runs or a PR-only run lookup as evidence for main.
- Updated skill contract: always preserve the UV-only original; dense-input high/low results are separate. Existing cap topology and sampled shape tolerances outrank polygon budget.
- Code assertions and regression coverage: level order must decrease face counts; low-poly must actually be smaller; reject boundary damage, surface damage, UV flips and metadata crossings; reload both files and inspect ZIP membership. Unsupported safe reduction produces explicit partial status, not a false duplicate.
- Real automatic-branch CI: a 262,144-quad synthetic rounded strap exceeds the default threshold; both operating systems create/check a commit-bound receipt. No production mesh is uploaded.
- Checkpoint guards include the new code and companion artifacts. Source/config/code changes require a fresh job; tampering blocks resume.

## Limits of the remedy

This repository stores executable checks and instructions for agents that read it. It does not modify a model's weights, guarantee that every future session reads these files, or promise zero recurrence. Report future capability/permission/tool failures from current observations. Numeric CI, generated previews, actual visual inspection, DCC import tests, host skill installation and lower-reasoning-model evaluations remain distinct evidence categories.
