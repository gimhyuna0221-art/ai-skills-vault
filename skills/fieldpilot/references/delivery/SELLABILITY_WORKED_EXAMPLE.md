# 이미 만든 앱을 팔아도 될까? — 가상 구매 판단 카드

**가상 사례: ShiftNote, 소형 매장의 교대 인수인계 웹앱. 실제 고객·매출·후기가 없는 설명용 예시입니다.** 아래 S1~S4는 모두 이 문서에만 존재하는 합성 입력이며 외부 검증 사실이 아닙니다. 실제 적용에서는 파일·화면·출처를 직접 읽어 확인해야 합니다.

## 사례 입력과 확인 범위

| ID | 합성 입력 | 근거 지위 |
|---|---|---|
| S1 | 데모 점검 기록에 인수인계 작성·검색 성공, 담당자 확인 기능 미구현. 배포 기록 없음. | 가상 점검 기록; 실제품 검증 아님 |
| S2 | 서로 다른 작성자의 가상 커뮤니티 글 2개에서 교대 때 메모 누락 호소. 가상 앱 리뷰 1개는 기존 채팅 검색으로 충분하다고 말함. | 두 출처 종류를 설명하기 위한 합성 문장; 실제 시장 빈도 아님 |
| S3 | 제작자의 가정: 매장 직원이 사용하고 점장이 비용 부담. 현재 매장은 기존 단체채팅을 사용한다고 가정. | 가정, 실사용·구매권한 미확인 |
| S4 | 사용자 제공 가격 아이디어: 1회 설치·초기설정 도움 10,000원. 유료 고객 0명. | 합성 가격 가설, 검증된 적정가격 아님 |

**외부 VERIFIED 시장 사실: 없음.** 실제 웹 조사·사용자 조사·결제 검증은 수행하지 않은 예시이므로 시장 범위는 LIMITED이며 실제 제품에 결론을 전용하면 안 됩니다.

| 구매 판단 항목 | 현재 답 |
|---|---|
| CURRENT_DECISION · 지금 판단 | 기능을 더 늘리기 전에, 인수인계 누락이 있는 소형 매장 점장이라는 **가정된 고객**에게 현재 제품의 설정 도움을 제안할 수 있는지 확인한다. 판매성은 UNKNOWN. |
| PAIN_SIGNAL_SYNTHESIS · 불편의 근거 | S2의 합성 커뮤니티 2건에 누락 문제가 반복되지만 리뷰 1건은 채팅으로 충분하다는 반대근거다. 이 작은 예시 표본으로 발생률이나 시장 수요를 말할 수 없다. |
| COMPETITIVE_ALTERNATIVES · 현재 대안 | 단체채팅, 종이 인수인계장, 기존 업무관리 앱, 그대로 두기. S3 외 실제 사용 근거는 없다. 직접 경쟁사 검색은 NOT_CHECKED이며 경쟁자가 없다는 뜻이 아니다. |
| MONEY_SHAPE · 누가 왜 돈을 내나 | 점장 지불은 S3의 가설. 대안의 추가 비용·최신 가격은 UNKNOWN. 팀원 교육과 기존 기록 이동은 예상 전환 부담이며 실제 측정은 없다. 현재 WTP는 UNKNOWN, 관측 결제 없음. |
| PRODUCT_STATE_DELTA · 제품과 필요한 것의 차이 | S1이라는 가상 입력 안에서는 작성·검색 IMPLEMENTED, 확인 기능은 미구현, 출시 여부 UNKNOWN. 실제 소스는 읽지 않았으므로 실제품 상태는 PRODUCT_STATE_UNAVAILABLE. 확인 기능의 고객가치는 UNKNOWN_GAP이며 CONFIRMED_GAP으로 올리지 않는다. |
| WHY_SWITCH_OR_NOT · 바꿔 쓸 이유 | 인수인계 내용을 따로 찾는 방식은 가능한 메시지 가설이다. 채팅 검색만으로 충분하면 이동·교육 부담을 감수할 이유가 없다. 실제 전환 이유·구매 선호는 UNKNOWN. |
| UNKNOWNS · 아직 모르는 것 | 반복 누락의 실제 빈도, 직접 경쟁사의 대안, 구매권한, 설정 비용, 결제·재사용. 도달 가능한 시장 규모는 자료 부족으로 NOT_DEFENSIBLE, 현재 시장 변화는 UNKNOWN. |
| BUILD_CHANGE_OR_HOLD · 바꾸거나 보류할 것 | 현재 제품 유지, 확인 기능·자동 알림 추가는 HOLD. 기존 데모로 설정 도움이라는 작은 제안을 준비한다. 결제 증거 없이 기능 투자를 확대하지 않는다. |
| FIRST_PAID_PROOF · 첫 결제 확인 | 아래 실험이 하나의 다음 행동이다. 준비는 AI가 먼저 하고, 실제 제안은 사용자 승인 이후에만 한다. |

## FIRST_PAID_PROOF — 실행 전 검토용

- **고객/입력:** 교대 메모 누락을 겪는 소형 매장 점장 한 명 / 개인정보를 지운 인수인계 메모 한 장.
- **제공할 것:** 현재 ShiftNote에 메모를 정리한 샘플과 1회 초기설정 도움. 추가 기능 개발은 포함하지 않는다.
- **가격 가설:** 10,000원 1회, S4의 제작자 제안일 뿐 시장가격 검증 아님. 이 조건의 실제 결제 여부를 확인한다.
- **AI가 지금 준비할 초안:** “교대 메모 한 장을 ShiftNote에서 다시 찾기 쉽게 정리하고 초기설정을 도와드립니다. 1회 10,000원이며 추가 기능 개발은 포함되지 않습니다.” 실제 제공 가능성은 먼저 확인한다.
- **범위/기간:** 승인 후 해당 점장 한 명에게 한 번 제안하고 7일 이내 반응을 확인한다. 아직 발송·게시·청구하지 않았다.
- **PASS:** 명시한 제공물에 대한 실제 10,000원 결제 기록이 확인됨. 동의·클릭·대기명단·미결제 청구서는 PASS가 아니다. 환불·취소 여부와 제공 완료를 별도로 기록한다.
- **STOP/HOLD:** 7일 내 결제가 없거나, 구매권한·제공 가능성이 확인되지 않으면 실험 HOLD. 추가 알림 기능부터 만들지 않는다. 거절 이유가 이미 제공되면 AI가 분석한다.
- **해석 한계:** 한 건 결제가 생겨도 그 거래의 OBSERVED_PURCHASE만 확인된다. 일반 WTP·PMF·매출 성장·재구매는 UNKNOWN이다. 실험을 건너뛰어도 현재 제한적 판단은 유지한다.
