# FieldPilot

**v1.9.9-rc04 (candidate) — AI-First Market Research + Prompt-Skill Independence + Lifecycle Decision Routing + Local Coverage**

FieldPilot은 바이브코더와 AI-assisted builder가 이미 쓰는 AI 안에서 시장조사를 가능한 한 대신 수행하고, 그 근거를 지금 무엇을 만들고·바꾸고·보류할지 결정하는 데 연결하는 Agent Skill입니다.

## 핵심 원칙

- 공개 웹·기존 자료·사용자가 이미 준 자료로 할 수 있는 조사는 FieldPilot이 먼저 합니다.
- 새 설문·인터뷰·모집은 기본 숙제가 아닙니다.
- 실제 수요·지불의사처럼 확인하지 못한 것은 꾸며내지 않고 `UNKNOWN`으로 남깁니다.
- 근거가 충분하면 만들 범위와 만들지 말아야 할 범위를 구체화합니다.
- 사용자가 이미 가진 피드백·테스트·결제·가입·사용 기록을 가져오면 이전 판단과 연결해 업데이트합니다.
- 명시적인 전체 시장조사 요청에는 기존 전문 보고서 경로를 유지합니다.
- 타깃 지역이 의사결정을 바꾸는 경우 글로벌 결과만으로 끝내지 않습니다. 한국이 명시되면 국내 경쟁·대체재·규제·접근 채널을 조건부로 점검하고, 지역이 미상일 때는 한국으로 추측하지 않습니다. 지역을 몰라도 먼저 답하고, 지역 질문은 답의 끝에 한 번만 합니다.
- 프롬프트를 잘 써야 좋은 결과가 나오는 도구가 아닙니다. 짧게, 평소 말로, 오타가 섞여도 같은 사례면 같은 깊이로 조사합니다. 말투와 길이는 달라져도 경쟁·대안, 제품 상태, 반대 근거, 모르는 것, 돈 관련 판단의 한계, 만들기·바꾸기·보류, 다음 행동 하나는 똑같이 챙깁니다.
- 질문은 꼭 필요할 때만 합니다. 찾을 수 있는 건 찾고, 추론할 수 있는 건 가정으로 밝히고, 먼저 답한 뒤 결론을 바꿀 질문만 끝에 최대 2개 묻습니다. 무엇인지 전혀 알 수 없을 때만 먼저 묻습니다.

## 개떡같이 말해도 됩니다

```text
/fieldpilot
앱 만들었는데 아무도 안 써. 이거 망한 거야? 광고해야 돼? 뭐부터 해?
```

```text
/fieldpilot
헬스장 프론트용 회원권 계산 앱인데 이거 팔릴까?
```

```text
/fieldpilot
관심은 있는데 결재를 안 해 ㅠ 뭐가 문제야
```

아래처럼 길게 써도 되지만, 필수는 아닙니다. 같은 사례면 짧게 물어도 조사 깊이는 같습니다.

## 어느 단계에서든 같은 명령어

FieldPilot은 사용자가 내부 모드를 고르지 않아도 현재 단계와 질문을 보고 필요한 조사/진단 경로를 선택합니다.

### 아이디어 단계

```text
/fieldpilot

이 아이디어 이미 레드오션인지, 누가 고객 후보인지, 사람들이 지금 뭘로 해결하는지,
지금 뛰어들 만한 근거와 반대 근거를 조사해줘.
```

### MVP / 개발 중

```text
/fieldpilot

지금 만든 기능과 경쟁 제품을 비교해서 뭘 더 만들고, 뭘 미루고, 뭘 빼야 할지 조사해줘.
```

### 출시 후 반응이 없을 때

```text
/fieldpilot

출시했는데 반응이 없어. 서비스 문제인지, 노출/메시지/채널 문제인지,
측정이나 제품 문제가 섞였는지 나눠서 보고 지금 가장 먼저 확인할 걸 정해줘.
```

### 홍보/광고가 막힐 때

```text
/fieldpilot

이 제품은 어디에서 어떤 방식으로 처음 홍보하는 게 가장 말이 되는지 조사해줘.
플랫폼 목록 말고 첫 채널 하나와 대안 하나, 실제 테스트 방법과 측정 기준까지 줘.
```

### 관심은 있는데 결제가 안 될 때

```text
/fieldpilot

사람들은 보는데 결제로 안 이어져. 가격/패키징, 쓰는 사람과 돈 내는 사람 차이,
결제 경로, 신뢰, 제품 가치 중 뭐가 문제일 수 있는지 근거로 좁혀줘.
```

주의: FieldPilot은 `대박/망함`, PMF, WTP, 광고 성과를 보장하지 않습니다. 대신 현재 근거에서 가장 강한 판단, 반대 근거, 아직 모르는 것, 다음 행동 하나를 줍니다.

## 빠른 사용

```text
/fieldpilot

이미 만든 내 앱·웹서비스를 팔 수 있을지 조사해줘. 네가 조사할 수 있는 건 직접 조사하고,
현재 근거로 지금 무엇을 만들거나 바꾸거나 보류해야 하는지 알려줘.
```

반응이 이미 생겼다면:

```text
/fieldpilot

사용자 피드백이 왔어. 이전 판단과 비교해서 무엇이 바뀌는지 봐줘.
```

## 제한사항

- 호스트 모델·검색·도구 능력에 따라 실제 조사 범위가 달라집니다.
- 경쟁사의 비공개 매출·다운로드·리텐션은 직접 확인할 수 없는 경우가 많습니다.
- 사용자 직접조사를 생략하면 제품 특이적 수요/WTP가 미확인으로 남을 수 있습니다.
- 실제 매출, PMF, 성공을 보장하지 않습니다.

## 판매 판단 예시

[가상 제품의 구매 판단 카드](references/delivery/SELLABILITY_WORKED_EXAMPLE.md)는 실제 고객 후기나 성과가 아닙니다. 넓은 판매 질문에는 현재 대안, 돈을 내는 사람, 전환 이유, 제품 상태와 첫 결제 실험을 함께 정리합니다. 가격 사실만 묻는 질문은 짧게 답합니다.

필요한 판단에는 치명적 위험과 대응, 근거가 있는 변경안, 성공·실패·보류 기준이 있는 실험을 붙입니다. 개발을 선택하면 기존 코딩 AI에 전달할 범위와 완료 조건을 정리합니다. 경쟁 제품보다 우수하다는 비교 결과는 아직 없습니다.
