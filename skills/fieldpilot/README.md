# Field Pilot

외부 사용자를 모집해 실제 현장에서 제품을 검증하는 재사용 스킬입니다.

설문·모집처럼 특정 단계를 콕 집어 요청해도, 그보다 앞선 단계(검증
목적·가설 등)가 아직 없으면 결과부터 만들어내지 않고 먼저 확인합니다.
앞선 단계가 이미 끝났다는 근거가 있으면 처음부터 다시 묻지 않습니다.

## 호출 예시

```text
/fieldpilot
새로 만든 업무 앱을 외부 사업장 5곳에서 검증하고 싶어.
```

## 적용 범위

- 검증 가설
- 모집 조건
- 소개서·첫 접촉
- 온보딩
- 파일럿 운영
- 종료 설문
- 모집 퍼널
- 결과 해석
- 개선 우선순위
