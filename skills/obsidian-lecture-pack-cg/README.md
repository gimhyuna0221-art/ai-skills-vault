# Obsidian Lecture Pack — CG Omnibus

여러 학생이 서로 다른 캐릭터 제작 단계에서 순차적으로 피드백받는
CG 옴니버스 수업 전용 독립 스킬입니다.

현재 버전: `4.2.0`  
상태: `stable draft`

## 사용 대상

- 학생별 작업물과 제작 단계가 다름
- 강사가 학생을 순서대로 피드백함
- 같은 학생이 강의 중 또는 다음 강의에 다시 등장함
- 이전 피드백 반영 여부와 현재 제작 단계를 이어서 추적해야 함
- 학생 이력·공용 개념·11단계 캐릭터 워크플로우를 누적해야 함

학생이 없거나 학생별 진도 추적이 없는 CG 튜토리얼은
일반 `obsidian-lecture-pack`을 사용합니다.

## 일반 강의 스킬과의 차이

일반 강의 스킬은 주제·개념·절차 중심입니다.

CG 옴니버스 스킬은 다음 정보를 장기적으로 이어가는 것이 핵심입니다.

- 학생별 안정적 ID와 aliases
- 같은 학생의 재등장 세션
- 이전 피드백과 반영 여부
- 현재 제작 단계와 다음 과제
- 개인 사례와 공용 원칙의 분리
- 캐릭터 제작 11단계 통합 워크플로우

그래서 CG 스킬은 기본적으로 누적형입니다.
일반 강의 단독 모드처럼 동기화팩을 생략하는 모드를 기본으로 두지 않습니다.

## 매주 필요한 입력

1. 최신 `00_매주_ChatGPT에_보낼_AI동기화팩.zip`
2. 이번 주 SBV/SRT/VTT 또는 YouTube 시간 표시 스크립트
3. 이번 주 NotebookLM CG 옴니버스 분석본
4. YouTube URL
5. 강의 날짜·과정명·강사명
6. 선택 이미지
7. 정확한 과거 비교가 필요할 때만 해당 날짜의 원문전사

동기화팩이 없으면 이번 강의만으로 초기화할 수 있지만,
과거 강의와 누적 병합했다고 주장하지 않습니다.

## 매주 처리 흐름

```text
지난주 최신 CG 동기화팩
+ 이번 주 자막·NotebookLM 분석·YouTube URL
→ 학생 세션과 재등장 검증
→ 학생별 이력 갱신
→ 공용 개념 병합
→ 캐릭터 제작 11단계 워크플로우 병합
→ 인덱스·병합 로그·지식 간극 갱신
→ 다음 주에 다시 줄 최신 CG 동기화팩 완전 재생성
```

## 핵심 산출물

- 날짜별 강의 기록
- 학생별 진행 이력과 재등장 연결
- 공용 개념
- 캐릭터 제작 11단계 워크플로우
- 강의 인덱스와 소스 인덱스
- 병합 로그와 지식 간극
- 완전 재생성된 AI 동기화팩
- `옵시디언_CG_주간업데이트.zip`

## 사용자 전달 구조

```text
옵시디언_CG_주간업데이트.zip
├─ 새 강의와 갱신된 학생·개념·워크플로우 파일
├─ 갱신된 인덱스·검토 대기·병합 로그
└─ 00_매주_ChatGPT에_보낼_AI동기화팩.zip
```

사용자는 결과 ZIP의 볼트 파일을 기존 `캐릭터_모델링` 저장소에
한 번 덮어씌웁니다.

다음 주 처리에는 결과물 안의 최신
`00_매주_ChatGPT에_보낼_AI동기화팩.zip`을 다시 제공합니다.

## CG 동기화팩

매 병합 후 부분 수정하지 않고 완전 재생성합니다.

포함:

- AI 허브, 과정목차, 강의 인덱스
- 소스 인덱스, 지식 간극, 병합 로그
- 학생 사례 전체
- 개념 전체
- 캐릭터 워크플로우 전체
- 모든 강의의 목차·북마크·최종노트
- 현재 CG SKILL, manifest, CG NotebookLM 프롬프트
- 파일 목록과 SHA-256 manifest

제외:

- 모든 과거 원문전사
- 원본 자막·이미지·영상
- NotebookLM 원본
- 검사·임시 파일과 `.obsidian`

## 일반 누적 동기화팩과의 관계

일반 강의 누적 모드도 다음 처리용 동기화 ZIP을 만들 수 있지만,
CG 동기화팩과는 구조와 목적이 다릅니다.

```text
일반 누적팩
→ 같은 분야의 강의·개념·분야별 워크플로우

CG 동기화팩
→ 학생 이력·재등장·피드백·11단계 캐릭터 워크플로우
```

두 동기화팩은 서로 병합하지 않습니다.
