# Obsidian Lecture Pack — CG Omnibus

여러 학생이 서로 다른 캐릭터 제작 단계에서 순차적으로 피드백받는 CG 옴니버스 수업 전용 독립 스킬입니다.

현재 버전: `4.2.0`  
상태: `stable draft`

## 사용 대상

- 학생별 작업물과 제작 단계가 다름
- 강사가 학생을 순서대로 피드백함
- 같은 학생이 강의 중 또는 다음 강의에 다시 등장함
- 학생 이력·공용 개념·11단계 캐릭터 워크플로우를 누적해야 함

학생이 없는 CG 튜토리얼은 일반 `obsidian-lecture-pack`을 사용합니다.

## 호출

```text
/obsidian-cg
/obsidianpack-cg
```

## NotebookLM 프롬프트

```text
prompts/notebooklm-cg-omnibus-feedback.md
```

## 핵심 산출물

- 날짜별 강의 기록
- 학생별 진행 이력과 재등장 연결
- 공용 개념
- 캐릭터 제작 11단계 워크플로우
- 완전 재생성된 AI 동기화팩
- `옵시디언_CG_주간업데이트.zip`
