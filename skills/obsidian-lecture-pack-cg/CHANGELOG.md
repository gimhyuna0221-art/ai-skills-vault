# Changelog

## 4.3.0 — 2026-08-04

### Changed

- 강의는 날짜별 독립 기록으로 보존하고 워크플로우는 최종 본문으로 통합하는 4계층 구조 확정
- 워크플로우를 날짜별 `강의 반영` 섹션으로 덧붙이지 않고 기존 본문을 재작성하도록 변경
- 워크플로우 변경 상태를 `body_integrated`, `evidence_only`, `candidate_pending`, `no_change`로 구분
- `00_전체 파이프라인.md`의 근거·성숙도·단계 상태 갱신을 처리 절차에 추가
- 요일·반 정보 `class_group`을 학생 식별 기준에 추가
- 같은 이름이 다른 반에 존재하면 별도 학생으로 관리
- 명령이 `/obsidianpack`이어도 명백한 CG 옴니버스 입력이면 자동 라우팅하도록 보강

### Fixed

- 새 강의 내용을 워크플로우 끝에 날짜별 섹션으로만 추가하고 병합 완료로 판정하던 문제 수정
- 워크플로우 본문을 갱신하지 않고 `단계 갱신 완료`로 보고할 수 있던 허점 차단
- 기존 저장소 폴더를 삭제하고 교체할 수 있는 모호한 안내를 폴더 병합 방식으로 수정
- 분석·검증 후 결과 ZIP을 생성하지 않은 채 작업이 종료될 수 있던 문제를 완료 원자성 규칙으로 차단
- 다른 요일·반의 동명이인이 하나의 학생 노트로 합쳐질 위험 차단

### Documentation

- 강의·학생 사례·개념·워크플로우의 역할을 분리해 README에 명시
- 워크플로우 정식 본문 스키마와 병합 완료 기준 추가
- 반·학생 식별 우선순위와 동명이인 처리 규칙 추가
- 결과 ZIP 적용 시 기존 `캐릭터_모델링` 폴더를 삭제하지 않는다고 명시

### Validation

- 2026-07-29과 2026-08-02 강의 근거를 8개 워크플로우 단계 본문으로 재통합
- 날짜별 `강의 반영` 섹션 잔존 0개 확인
- 전체 파이프라인에 두 강의 근거 반영
- 깨진 링크·모호한 링크·중복 ID 0개 확인
- 동기화팩 해시와 ZIP 무결성 확인

## 4.2.0 — 2026-08-02

### Changed

- 일반 강의 스킬에서 분리해 CG 옴니버스 전용 독립 스킬로 구성
- 명령을 `/obsidian-cg`와 `/obsidianpack-cg`로 분리
- 캐릭터 모델링 v4.1의 학생 이력·증분 동기화·안정적 ID 구조 유지
- YouTube 시간 표시 스크립트와 사용자용/내부자료 분리 규칙 추가

### Fixed

- 일반 강의 프롬프트와 필드가 CG 결과에 섞일 가능성 차단
- 일반 강의용 동기화팩과 자동 병합하지 않도록 차단

### Documentation

- CG 스킬이 기본 누적형인 이유를 README에 명시
- 매주 최신 동기화팩을 다음 처리에 다시 제공하는 흐름을 명시
- 학생 ID·aliases·재등장·이전 피드백·현재 제작 단계 보존 목적을 명시
- 일반 누적 동기화팩과 CG 동기화팩의 구조·목적 차이를 명시
- 동기화팩 포함·제외 항목과 사용자 전달 구조를 명시

### Validation

- 사용자 수동 확인으로 CG 결과의 학생 피드백 중심 구조 확인
- 일반 강의 결과와 분리된 출력 확인
- 반복 병합·aliases·동기화팩 교체는 정식 검증 대기
