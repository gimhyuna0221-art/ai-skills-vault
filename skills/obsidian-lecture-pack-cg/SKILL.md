# Obsidian Lecture Pack — CG Omnibus v4.2

## 역할과 경계

이 스킬은 여러 학생이 서로 다른 캐릭터 제작 단계에서 순차적으로 피드백받는 옴니버스형 수업 전용이다.

분석 단위:
- 학생, 대상, 작업물, 현재 제작 단계
- 이전 피드백과 반영 여부
- 피드백 세션과 재등장 세션
- 수정 순서, 완료 판단 기준, 다음 확인 항목
- 개인 사례와 공용 원칙

학생이 없거나 학생별 진도 추적이 없는 CG 튜토리얼은 처리하지 않는다.
해당 입력이면 이 작업을 중단하고 독립 스킬 `obsidian-lecture-pack`을 사용한다.

NotebookLM에는 이 폴더의 `prompts/notebooklm-cg-omnibus-feedback.md`만 사용한다.
일반 강의 프롬프트를 섞지 않는다.

## 최종 목표

```text
매주 CG 옴니버스 수업
→ 검증된 강의 기록
→ 학생별 진행 이력
→ 공용 개념
→ 캐릭터 제작 11단계 워크플로우
→ 근거·앵커·타임스탬프가 있는 제2의 뇌
```

공식 지식베이스 폴더명은 `캐릭터_모델링`으로 유지한다.
기존 경로, 사용자 문장, 안정적 ID를 임의 변경하지 않는다.

## 명령

- `/obsidian-cg` 또는 `/obsidianpack-cg`: 이번 주 강의 검증·증분 병합
- `/obsidian-cg-full`: 원본·검사자료까지 확장 전달
- `/obsidian-cg-sync-rebuild`: 실제 최신 저장소에서 동기화팩 완전 재생성
- `/obsidian-cg-lint`: 링크·ID·중복·학생 aliases·지식 간극 검사
- `/obsidian-cg-query`: 근거와 함께 지식베이스 질의

일반용 `/obsidianpack`을 CG 스킬의 트리거로 사용하지 않는다.

## 기본 입력

1. 최신 `00_매주_ChatGPT에_보낼_AI동기화팩.zip`
2. 이번 주 SBV/SRT/VTT 또는 YouTube 시간 표시 스크립트
3. 이번 주 NotebookLM CG 옴니버스 분석본
4. YouTube URL
5. 강의 날짜·과정명·강사명
6. 선택 이미지
7. 정확한 과거 비교가 필요할 때만 해당 날짜의 원문전사

동기화팩이 없으면 현재 강의만으로 초기화할 수 있지만, 과거와 누적 병합했다고 주장하지 않는다.
manifest가 손상되거나 일반 강의용 동기화팩이면 병합을 중단한다.

## 근거 우선순위

1. SBV/SRT/VTT처럼 시작·종료 시간이 있는 자막
2. YouTube `스크립트 표시`에서 복사한 시간 표시 스크립트
3. 시간 없는 전사문 또는 TXT
4. NotebookLM 분석본
5. 화면 캡처와 사용자 메모
6. 사용자가 명시적으로 허용한 외부 자료

원문과 NotebookLM 분석이 충돌하면 원문을 우선한다.
NotebookLM 발췌 번호는 영상 타임스탬프로 사용하지 않는다.
시간이 없으면 시간을 추측하거나 균등 배분하지 않는다.
외부 지식으로 강의 내용을 몰래 보충하지 않는다.

## 학생과 세션 검증

- 학생 이름을 추측하지 않는다.
- 불확실하면 `name_status: verify`로 두고 기존 학생과 자동 병합하지 않는다.
- aliases와 이름 후보를 기록한다.
- 같은 학생이 강의 중 다시 등장하면 재등장 세션으로 연결한다.
- 개인 형태 수정과 다른 캐릭터에도 적용 가능한 원칙을 분리한다.
- 학생의 수업 외 사적 정보는 지식 노트에서 제외한다.

## 캐릭터 제작 단계

1. 레퍼런스와 기획
2. 블록아웃과 비례
3. 얼굴과 인체 스컬핑
4. 의상과 주름
5. 헤어와 카드
6. 하드서페이스와 장신구
7. 리토폴로지
8. UV와 베이크
9. 텍스처와 재질
10. 리깅 대응
11. 최종 검수

단계가 불확실하거나 여러 단계에 걸치면 후보를 복수로 적는다.
강의에서 다루지 않은 단계를 억지로 채우지 않는다.

## 처리 절차

1. 동기화팩 manifest·버전·파일 목록·SHA-256을 검사한다.
2. 자막 인코딩·시간·전체 길이를 확인한다.
3. NotebookLM 앵커와 원문을 대조한다.
4. 학생 이름, 세션 경계, 재등장을 검증한다.
5. 북마크 시작 시각과 YouTube `t=` 초를 계산한다.
6. 개인 피드백과 공용 개념·원칙을 분리한다.
7. 기존 학생·개념·워크플로우와 의미 중복을 검사한다.
8. 학생 사례에 날짜별 세션을 추가한다.
9. 공용 개념과 캐릭터 워크플로우에 근거를 병합한다.
10. 강의 인덱스와 소스 인덱스, 병합 로그, 지식 간극을 갱신한다.
11. AI 동기화팩을 부분 수정하지 않고 완전 재생성한다.
12. 오류 수정 후 링크·ID·manifest를 재검사한다.

```text
│     ├─ 01_원문전사.md
│     ├─ 02_북마크.md
│     └─ 03_최종노트.md
├─ 학생 사례/
├─ 개념/
├─ 캐릭터 워크플로우/
└─ _시스템/
```

## 지식 병합 규칙

학생 사례:
- 기존 학생은 날짜별 기록을 추가한다.
- 이름이 불확실하면 자동 병합하지 않는다.

공용 개념:
- 같은 의미의 개념은 새 노트를 만들지 않고 강의별 근거를 추가한다.
- 특정 학생에만 해당하는 내용은 학생 사례에 남긴다.

캐릭터 워크플로우:
- 목적, 선행 조건, 순서, 중간·완료 기준, 실패 증상, 원인, 예방, 복구를 해당 단계에 병합한다.

지식 성숙도:
- `case → recurring → principle → standard`
- 한 강의나 한 학생 사례만으로 `standard`를 부여하지 않는다.

## AI 동기화팩

매 병합 후 완전 재생성한다.

포함:
- AI 허브, 과정 목차, 강의 인덱스
- 소스 인덱스, 지식 간극, 병합 로그
- 학생 사례 전체, 개념 전체, 캐릭터 워크플로우 전체
- 모든 강의의 목차·북마크·최종노트
- 현재 CG SKILL.md, manifest.json, CG NotebookLM 프롬프트
- 파일 목록과 SHA-256 manifest

제외:
- 모든 과거 원문전사
- 원본 자막, 이미지, 영상
- NotebookLM 원본
- 검사·임시 파일, `.obsidian`

제외된 원문전사 링크는 동기화팩 안에서 깨진 링크로 남기지 않는다.

## 사용자 전달

```text
옵시디언_CG_주간업데이트.zip
```

ZIP은 현재 저장소 상대 경로를 유지하며 다음을 포함한다.
- 새 강의와 갱신된 학생·개념·워크플로우 파일
- 갱신된 인덱스와 검토 대기·병합 로그
- 완전 재생성된 `00_매주_ChatGPT에_보낼_AI동기화팩.zip`

사용자는 저장소에 한 번 덮어씌운다.

## 품질검사

- 깨진·모호한 내부 링크
- 중복 ID·파일명·유사 개념
- 학생 이름·aliases 충돌
- 재등장 세션 연결 누락
- 학생별 진도·이전 피드백 보존
- 개인 사례의 과잉 일반화
- 근거 없이 `standard`가 된 항목
- 시간값 오름차순·앵커 일치·YouTube 초 계산
- 소스 중복과 처리 누락
- 지식 간극 미해결 항목
- 동기화 manifest 파일 목록·해시 불일치
