# Obsidian Lecture Pack Builder

## 목적

강의 영상, YouTube URL, 시간 표시 스크립트, NotebookLM 정리본,
SBV/SRT/VTT/TXT 자막을 받아 단순 요약이 아니라 다음 자료가 연결된
Obsidian 강의 지식팩을 만든다.

이 스킬은 공통 처리 엔진과 분야별 분석 프로필을 분리한다.

- 공통 엔진: 원문 보존, 앵커 대조, 시간 계산, 북마크, 개념 노트, 링크 검사, ZIP 생성
- 분야별 프로필: 분석 단위, 전문용어, 단계별 워크플로우, 완료 기준

CG 강의에는 CG 전용 프로필을 사용하고,
일반 강의에는 범용 프로필 또는 해당 분야의 프로필을 사용한다.

선택하지 않은 다른 분야의 프로필과 개발용 문서를
사용자용 Obsidian 폴더에 포함하지 않는다.

## 기본 산출물

사용자용 Obsidian 폴더에는 다음 자료만 포함한다.

1. `00_AI허브.md`
2. `00_과정목차.md`
3. `강의/`
4. `개념/`
5. `워크플로우/`
6. 강의별 `00_강의목차.md`
7. 강의별 `01_원문전사.md`
8. 강의별 `02_북마크.md`
9. 강의별 `03_최종노트.md`

검사자료와 AI 동기화 자료는 사용자용 Obsidian 폴더와 분리한다.

## 권장 입력

1. 강의명
2. 강의 날짜
3. 강사명
4. 강의 분야
5. YouTube URL 또는 영상 정보
6. 시간 정보가 있는 자막 또는 스크립트
7. NotebookLM 분석본
8. 필요한 화면 캡처와 메모
9. 누적 병합이 필요한 경우 최신 AI 동기화팩

## 입력 우선순위

시간과 원문 검증에는 다음 순서를 사용한다.

1. `SBV/SRT/VTT`처럼 시작·종료 시간이 포함된 자막
2. YouTube `스크립트 표시`에서 복사한 시간 표시 스크립트
3. 시간 없는 일반 전사문 또는 TXT
4. NotebookLM 분석본
5. 화면 캡처와 사용자 메모
6. 사용자가 명시적으로 허용한 외부 자료

원문과 NotebookLM 분석본이 충돌하면 원문을 우선한다.

NotebookLM의 발췌 번호는 실제 영상 시간으로 사용하지 않는다.

외부 지식으로 강의 내용을 몰래 보충하지 않는다.

전사에서 확인되지 않는 정보는 `근거 부족` 또는
`확인되지 않음`으로 표시한다.

## YouTube 시간 표시 스크립트 가져오기

공개 YouTube 영상에 스크립트가 제공되면 다음 절차를 사용한다.

1. YouTube 영상을 연다.
2. 영상 설명 영역의 `더보기`를 누른다.
3. 아래쪽의 `스크립트 표시`를 누른다.
4. 스크립트 창에서 시간 표시가 보이는 상태로 둔다.
5. 처음부터 끝까지 선택하여 복사한다.
6. YouTube URL과 함께 제공한다.

허용되는 시간 형식:

- `0:00`
- `12:34`
- `1:02:03`

각 시간값은 바로 뒤에 나오는 발화의 시작 시각으로 해석한다.

YouTube 자동 생성 스크립트는 오인식과 문장 분할 오류가 있을 수 있다.

따라서 다음 원칙을 지킨다.

- 원문 자막은 그대로 보존한다.
- 교정 후보는 원문과 분리해 기록한다.
- 전문용어를 추측으로 확정하지 않는다.
- 작품명, 인명, 프로그램명은 불확실성을 표시한다.
- 화면에서만 확인 가능한 예문이나 결과는 `화면 확인 필요`로 둔다.

시간값 없이 단독으로 나타나는 제목형 문구가 있으면
`챕터·주제 제목 후보`로 분리한다.

제목형 문구를 실제 강사의 발화로 단정하지 않는다.

## 작업 절차

### 1. 입력 유형 판별

입력 자료를 다음 중 하나로 구분한다.

- 시간 자막
- YouTube 시간 표시 스크립트
- 시간 없는 전사문
- NotebookLM 분석본
- 화면 캡처
- 사용자 메모

강의 분야를 확인하고 다음 중 하나를 선택한다.

- 범용 강의 프로필
- CG 캐릭터 모델링 프로필
- 웹소설 작법 프로필
- 기타 분야 프로필
- 신규 도메인 후보

선택된 프로필 하나만 사용한다.

선택하지 않은 분야의 프로필을 결과물에 섞지 않는다.

기존 AI 동기화팩이 없으면 누적 병합을 수행했다고 주장하지 않는다.

이 경우 제공된 자료만으로 초기 강의팩을 만들고
상태를 `initialized`로 기록한다.

### 2. 원문 보존

- 자막과 스크립트를 원래 순서로 보존한다.
- 시간값을 제거하지 않는다.
- 챕터·주제 제목 후보와 실제 발화를 구분한다.
- 오탈자와 전문용어를 원문에서 임의로 수정하지 않는다.
- 교정이 필요하면 원문 표기와 교정 후보를 함께 기록한다.
- 원본 자막·전사·영상·이미지를 삭제하지 않는다.
- 원본을 교정본으로 덮어쓰지 않는다.

### 3. 강의 구조 분석

일반 강의는 다음 단위로 나눈다.

- 주제
- 챕터
- 사례
- 예문
- 실습
- 질의응답
- 절차
- 도구 설명

옴니버스형 강의는 다음 단위로 나눈다.

- 학생
- 대상
- 작업물
- 피드백 세션
- 제작 단계
- 재등장 세션

NotebookLM 분석본은 구조 후보로 사용한다.

NotebookLM이 제안한 구간과 원문 앵커가 일치하는지 확인한다.

강사의 직접 설명과 AI의 분석 후보를 구분한다.

AI의 추론이 포함되면 `분석 후보`라고 표시한다.

### 4. 앵커 생성

각 주제나 세션마다 다음을 만든다.

- 시작 앵커
- 끝 앵커
- 주제명
- 한 줄 설명
- 시간 근거
- 불확실성

앵커는 원문 그대로 5~15어절을 사용한다.

공백과 문장부호 차이는 정규화할 수 있다.

의미가 다른 문장을 억지로 매칭하지 않는다.

같은 문장이 여러 번 등장하면 주제 전환 위치와 가장 가까운 구간을 선택한다.

매칭이 불확실하면 `검토 필요`로 표시한다.

### 5. 실제 북마크 생성

#### SRT/SBV/VTT

시작·종료 시간이 모두 있으면 실제 시간을 사용한다.

각 주제 구간에 다음을 기록한다.

- 시작 시각
- 종료 시각
- YouTube 클릭 링크
- 설명
- 시작 앵커
- 끝 앵커
- 시간 근거 유형

#### YouTube 시간 표시 스크립트

일치한 첫 발화의 시간값을 북마크 시작 시각으로 사용한다.

시간값을 초 단위로 변환한다.

계산 방식:

```text
분:초
→ 분 × 60 + 초

시:분:초
→ 시 × 3600 + 분 × 60 + 초
