# Obsidian Lecture Pack Builder

## 목적

강의 영상, YouTube 링크, NotebookLM 정리본, SBV/SRT/VTT/TXT 자막을 받아
단순 요약 노트가 아니라 다음 자료가 모두 연결된 완전한 Obsidian 강의 지식팩을 만든다.

## 기본 산출물

1. `00_과정목차.md`
2. `01_원문전사.md`
3. `02_북마크.md`
4. `03_최종노트.md`
5. `개념노트/`
6. `98_검사결과.md`
7. `99_설치방법.md`
8. 전체 결과 ZIP

## 입력 우선순위

1. 사용자가 제공한 원문 자막 또는 전사문
2. 사용자가 제공한 NotebookLM 정리본
3. 사용자가 제공한 화면 캡처·메모
4. 사용자가 명시적으로 허용한 외부 자료

원문과 요약이 충돌하면 원문을 우선한다.
외부 지식으로 강의 내용을 몰래 보충하지 않는다.
전사에서 확인되지 않는 정보는 `근거 부족`으로 표시한다.

## 작업 절차

### 1. 원문 보존

- 자막을 실제 시작·종료 시간과 함께 Markdown으로 변환한다.
- 오탈자와 전문용어를 임의로 고치지 않는다.
- 교정이 필요하면 원문과 교정본을 분리한다.
- 원본 파일을 삭제하거나 덮어쓰지 않는다.

### 2. 실제 북마크 생성

- NotebookLM 발췌 번호를 실제 타임스탬프로 오인하지 않는다.
- 자막 기준으로 주제 전환 지점을 찾는다.
- 각 북마크에 한 줄 설명을 붙인다.
- YouTube URL이 있으면 초 단위 링크를 만든다.

### 3. 최종 강의노트 생성

- 강의 전체 목차
- 세 문장 요약
- 주제별 시간 구간
- 단계별 작업 순서
- 기능·도구·단축키
- 강사가 강조한 원칙
- 실수하기 쉬운 부분
- 화면 확인이 필요한 부분
- 실습 체크리스트
- 용어집
- 복습 질문
- 다음 수업 전 복습 항목
- 관련 노트 링크

### 4. 개념 노트 완성

최종노트의 모든 `[[내부 링크]]`에 대응하는 실제 `.md` 파일을 만든다.
기존 노트는 승인 없이 덮어쓰지 않는다.
근거가 부족하면 억지로 작성하지 말고 상태를 표시한다.

### 5. MOC 생성

과정 목차에 최종노트, 원문전사, 북마크, 개념 노트, 이미지·영상·PDF를 연결한다.
관련성이 확인될 때만 개념끼리 연결한다.

### 6. 영상 연결

YouTube URL이 있으면 임베드와 초 단위 타임링크를 만든다.
로컬 MP4가 볼트 안에 있으면 `![[영상 파일명.mp4]]` 형식을 사용한다.
볼트 밖의 파일은 임의로 복사하지 않는다.

### 7. 품질검사

- 깨진 내부 링크
- 비어 있는 개념 노트
- 중복 파일명
- 잘못된 파일명
- YouTube 시간 계산
- 원문과 요약 충돌
- 이미지 경로
- 근거 부족 항목

## 안전 규칙

- 원본 자막·전사·영상·이미지를 삭제하지 않는다.
- 기존 노트를 승인 없이 덮어쓰지 않는다.
- 중복 의심 파일을 자동 삭제하지 않는다.
- 타임스탬프와 전문 내용을 추측하지 않는다.
- 강의에서 확인되지 않은 기능·수치·단축키를 추가하지 않는다.
