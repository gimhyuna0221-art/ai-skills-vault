Obsidian Lecture Pack Builder

목적

강의 영상, YouTube URL, 시간 표시 스크립트, NotebookLM 정리본,SBV/SRT/VTT/TXT 자막을 받아 단순 요약이 아니라 다음 자료가 연결된Obsidian 강의 지식팩을 만든다.

이 스킬은 공통 처리 엔진과 분야별 분석 프로필을 분리한다.

공통 엔진: 원문 보존, 앵커 대조, 시간 계산, 북마크, 개념 노트, 링크 검사, ZIP 생성

분야별 프로필: 분석 단위, 전문용어, 단계별 워크플로우, 완료 기준

CG 강의에는 CG 전용 프로필을 사용하고,일반 강의에는 범용 프로필 또는 해당 분야의 프로필을 사용한다.

선택하지 않은 다른 분야의 프로필과 개발용 문서를사용자용 Obsidian 폴더에 포함하지 않는다.

YouTube 시간 표시 스크립트 가져오기

공개 YouTube 영상에 스크립트가 제공되면 다음 절차를 사용한다.

YouTube 영상을 연다.

영상 설명 영역의 더보기를 누른다.

아래쪽의 스크립트 표시를 누른다.

스크립트 창에서 시간 표시가 보이는 상태로 둔다.

처음부터 끝까지 선택하여 복사한다.

YouTube URL과 함께 제공한다.

허용되는 시간 형식:

0:00

12:34

1:02:03

각 시간값은 바로 뒤에 나오는 발화의 시작 시각으로 해석한다.YouTube 자동 생성 스크립트는 오인식과 문장 분할 오류가 있을 수 있다.

따라서 다음 원칙을 지킨다.

원문 자막은 그대로 보존한다.

교정 후보는 원문과 분리해 기록한다.

전문용어를 추측으로 확정하지 않는다.

작품명, 인명, 프로그램명은 불확실성을 표시한다.

화면에서만 확인 가능한 예문이나 결과는 화면 확인 필요로 둔다.

시간값 없이 단독으로 나타나는 제목형 문구가 있으면 챕터·주제 제목 후보로 분리한다.제목형 문구를 실제 강사의 발화로 단정하지 않는다.

2. 원문 보존

자막과 스크립트를 원래 순서로 보존한다.

시간값을 제거하지 않는다.

챕터·주제 제목 후보와 실제 발화를 구분한다.

오탈자와 전문용어를 원문에서 임의로 수정하지 않는다.

교정이 필요하면 원문 표기와 교정 후보를 함께 기록한다.

원본 자막·전사·영상·이미지를 삭제하지 않는다.

원본을 교정본으로 덮어쓰지 않는다.

일치한 첫 발화의 시간값을 북마크 시작 시각으로 사용한다.시간값을 초 단위로 변환한다.

계산 방식:

분:초
→ 분 × 60 + 초

시:분:초
→ 시 × 3600 + 분 × 60 + 초

다음 주제 시작 시각은 이전 구간의 종료 후보로 사용할 수 있다.다만 명시적인 종료 시간이 없으면 정확한 종료 시각이라고 단정하지 않는다.종료 시간에는 종료 후보라고 표시한다.

시간 없는 전사문

클릭형 시간 링크를 만들지 않는다.원문 검색용 시작·끝 앵커만 만든다.

검사결과에 다음을 기록한다.

시간별 북마크: 미검증
사유: 시간 정보가 포함된 자막 또는 스크립트 없음

시간을 추측하거나 임의로 배분하지 않는다.

6. YouTube 클릭형 링크 생성

https://www.youtube.com/watch?v=VIDEO_ID&t=166s

Obsidian 북마크 예시:

## 인터미션 활용으로 분량 늘리기

- 시작: [02:46](https://www.youtube.com/watch?v=VIDEO_ID&t=166s)
- 종료 후보: 03:08
- 내용: 인터미션의 정의와 분량 확보 원리

8. 분야별 워크플로우 생성

이미 검증된 분야별 프로필이 있으면 해당 단계에 강의 내용을 배치한다.프로필이 없으면 이번 자료에서 확인되는 단계만 후보로 제안한다.

상태는 다음 중 하나를 사용한다.

recurring

principle

standard

한 강의나 한 사례만으로 standard를 부여하지 않는다.특정 분야의 워크플로우를 다른 분야에 그대로 적용하지 않는다.

예시:

CG 캐릭터 모델링
→ 학생·작업물·피드백·제작 단계 중심

→ 인풋 분석·기획·장면 목적·집필·화말·퇴고 중심

일반 이론 강의
→ 주제·개념·사례·절차·복습 중심
