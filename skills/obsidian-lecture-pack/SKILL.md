# Obsidian Lecture Pack — General v1.2

## 역할과 경계

이 스킬은 학생별 진도 추적이 없는 일반 강의 전용이다.

적용 대상:
- 설명형·주제형·이론형 강의와 설교
- 실습형·도구형·튜토리얼 강의
- 웹소설 작법, 인문학, 철학, 디자인 등 일반 강의
- 학생별 피드백이 없는 CG 튜토리얼

분석 단위:
- 주제, 챕터, 개념, 사례, 예문, 절차, 실습, 질의응답, 도구 설명

금지:
- 학생·수강생별 진도, 이전 피드백, 재등장 세션, 학생별 과제를 임의 생성하지 않는다.
- 여러 학생이 서로 다른 CG 제작 단계에서 순차적으로 피드백받는 수업은 처리하지 않는다.
- 해당 입력이면 이 작업을 중단하고 독립 스킬 `obsidian-lecture-pack-cg`를 사용한다.

NotebookLM에는 이 폴더의 `prompts/notebooklm-general.md`만 사용한다.
다른 스킬 폴더의 프롬프트를 상대 경로로 참조하지 않는다.

## 권장 입력

1. 강의명·날짜·강사명·분야
2. YouTube URL 또는 영상 정보
3. SBV/SRT/VTT 또는 YouTube 시간 표시 스크립트
4. NotebookLM 일반 강의 분석본
5. 필요한 화면 캡처와 메모
6. 누적 병합 시 같은 일반 강의 지식베이스의 최신 AI 동기화팩

## 근거 우선순위

1. SBV/SRT/VTT처럼 시작·종료 시간이 있는 자막
2. YouTube `스크립트 표시`에서 복사한 시간 표시 스크립트
3. 시간 없는 전사문 또는 TXT
4. NotebookLM 분석본
5. 화면 캡처와 사용자 메모
6. 사용자가 명시적으로 허용한 외부 자료

원문과 NotebookLM 분석이 충돌하면 원문을 우선한다.
NotebookLM 발췌 번호는 영상 타임스탬프로 사용하지 않는다.
시간이 없으면 시간을 추측하거나 균등 배분하지 않는다.
외부 지식으로 강의 내용을 몰래 보충하지 않는다.

## YouTube 시간 처리

허용 형식:
- `0:00`
- `12:34`
- `1:02:03`
- `0:055초`, `1:061분 6초`처럼 시간과 발화가 붙은 자동 복사 형식

시간값은 바로 뒤 발화의 시작 시각이다.
붙은 형식은 첫 유효 시간을 정규화하되 원문은 그대로 보존한다.

계산:
```text
분:초 → 분 × 60 + 초
시:분:초 → 시 × 3600 + 분 × 60 + 초
```

다음 주제의 시작 시각은 이전 구간의 `종료 후보`로만 쓴다.
명시된 종료 시간이 아니면 `종료`라고 단정하지 않는다.

## 처리 절차

1. 입력 유형과 일반 강의 여부를 판별한다.
2. 원문을 시간값과 원래 순서 그대로 보존한다.
3. NotebookLM 주제 경계와 원문 앵커를 대조한다.
4. 각 주제에 원문 그대로 5~15어절의 시작·끝 앵커를 만든다.
5. 검증된 시작 시각으로 YouTube `&t=초s` 링크를 만든다.
6. 최종노트, 개념 노트, 분야별 워크플로우 후보를 만든다.
7. 모든 내부 링크, 시간값, 앵커, 중복 개념을 검사한다.
8. 사용자용 볼트와 AI·검사 자료를 분리해 ZIP으로 제공한다.

## 사용자용 지식 구조

```text
분야명/
├─ 00_AI허브.md
├─ 00_과정목차.md
├─ 강의 인덱스.md
├─ 강의/
│  └─ YYYY-MM-DD 강의명/
│     ├─ 00_강의목차.md
│     ├─ 01_원문전사.md
│     ├─ 02_북마크.md
│     └─ 03_최종노트.md
├─ 개념/
└─ 워크플로우/
```

학생 사례 폴더를 만들지 않는다.

## 최종노트 최소 항목

- 강의 정보와 세 문장 요약
- 전체 목차와 주제별 시간 구간
- 핵심 주장과 근거
- 실제로 설명된 절차와 완료 기준
- 도구·기능·설정값
- 실수, 실패 증상, 설명된 원인·예방·복구
- 화면 확인 필요와 용어 교정 후보
- 복습 질문과 다음 행동
- 근거 부족 항목

강의에서 설명하지 않은 절차·원인·예외를 임의로 보충하지 않는다.

## 개념과 워크플로우

지식 상태:
- `case`
- `recurring`
- `principle`
- `standard`

한 강의만으로 `standard`를 부여하지 않는다.
같은 의미의 기존 개념이 있으면 새 노트를 만들지 않고 근거를 추가한다.
일반 강의의 분야가 서로 다르면 동기화팩을 자동 혼합하지 않는다.

## 패키징

초기 생성:
```text
옵시디언_일반강의팩.zip
├─ 볼트에_복사/분야명/
├─ AI_동기화용/00_매주_ChatGPT에_보낼_AI동기화팩.zip
├─ 검사자료/98_검사결과.md
└─ README.md
```

누적 병합:
```text
옵시디언_일반강의_주간업데이트.zip
```

사용자 볼트에는 강의·개념·워크플로우 노트만 넣는다.
`SKILL.md`, manifest, 검사·개발 문서와 NotebookLM 프롬프트는 볼트에 넣지 않는다.

## 품질검사

- 깨진·모호한 내부 링크 0개
- 시간값 오름차순과 초 계산 확인
- 앵커와 원문 일치
- 종료와 종료 후보 구분
- 원문과 NotebookLM 충돌 표시

- 학생·진도·이전 피드백 필드 혼입 금지
- 사용자용 볼트와 내부 자료 분리
