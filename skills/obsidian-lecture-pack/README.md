# Obsidian Lecture Pack

강의 영상, YouTube 시간 표시 스크립트, 자막, NotebookLM 분석본을 근거로
원문·북마크·최종노트·개념·분야별 워크플로우가 연결된 Obsidian 강의팩을 생성합니다.

현재 버전: `1.1.0`  
현재 상태: `stable draft`

## 호출

```text
/obsidianpack
```

```text
/옵시디언팩만들어줘
```

또는:

```text
옵시디언 강의팩 만들어줘.
```

## 지원 입력

- 강의명·날짜·강사명·분야
- YouTube URL
- SBV/SRT/VTT 자막
- YouTube `스크립트 표시`에서 복사한 시간 표시 스크립트
- 시간 없는 TXT 전사문
- NotebookLM 분석본
- 화면 캡처와 사용자 메모
- 누적 병합용 AI 동기화팩

## 시간 정보 우선순위

1. SBV/SRT/VTT
2. YouTube 시간 표시 스크립트
3. 시간 없는 전사문
4. NotebookLM 분석본

시간 정보가 있으면 검증된 시작 시각으로 클릭형 YouTube 북마크를 만듭니다.

시간 정보가 없으면 시간을 추측하지 않고 원문 검색용 앵커만 만듭니다.

## YouTube 스크립트 가져오기

1. YouTube 영상을 엽니다.
2. 영상 설명의 `더보기`를 누릅니다.
3. `스크립트 표시`를 누릅니다.
4. 시간 표시가 보이는 상태로 둡니다.
5. 스크립트 전체를 복사합니다.
6. YouTube URL과 함께 제공합니다.

YouTube 자동 생성 스크립트에는 오인식이 있을 수 있으므로
원문은 보존하고 교정 후보를 별도로 기록합니다.

## 분야별 처리

공통 처리 엔진과 분야별 프로필을 분리합니다.

- 일반 강의: 주제·개념·사례·절차·복습 중심
- CG 강의: 학생·작업물·피드백·제작 단계 중심
- 웹소설 작법: 인풋 분석·기획·장면 목적·집필·화말·퇴고 중심
- 신규 분야: 자료에서 확인되는 단계만 후보로 생성

선택하지 않은 다른 분야의 프로필은 결과물에 포함하지 않습니다.

## 결과 ZIP 구조

```text
옵시디언_강의팩.zip
├─ 볼트에_복사/
│  └─ 분야명/
│     ├─ 00_AI허브.md
│     ├─ 00_과정목차.md
│     ├─ 강의/
│     ├─ 개념/
│     └─ 워크플로우/
├─ AI_동기화용/
│  └─ 00_매주_ChatGPT에_보낼_AI동기화팩.zip
├─ 검사자료/
└─ README.md
```

사용자는 `볼트에_복사/분야명/`만 Obsidian 볼트에 넣습니다.

`SKILL.md`, 도메인 프로필, 검사결과, 설치문서, 내부 시스템 규칙은
사용자용 볼트에 넣지 않습니다.

## 검증 현황

### 통과

- 일반 강의 자료로 강의팩 생성
- Obsidian에서 노트 열기
- 원문·최종노트·개념·워크플로우 생성
- 내부 링크 검사

### 재검증 필요

- YouTube 시간 표시 스크립트 기반 클릭형 북마크
- 사용자용 볼트와 내부 자료의 완전 분리
- 서로 다른 실제 강의 3회 이상 반복 실행
- 처음 사용하는 사람이 README만 보고 실행 가능한지 확인

자세한 기준과 실행 기록은
[Validation Log](VALIDATION_LOG.md)에서 확인할 수 있습니다.

## 현재 알려진 한계

- YouTube 자동 자막의 전문용어·인명·작품명은 틀릴 수 있습니다.
- 화면에만 표시된 예문·설정값은 자막만으로 복원할 수 없습니다.
- 한 강의에서 추출한 원칙은 `standard`로 확정하지 않습니다.
- 기존 AI 동기화팩이 없으면 과거 지식과 병합했다고 주장하지 않습니다.
