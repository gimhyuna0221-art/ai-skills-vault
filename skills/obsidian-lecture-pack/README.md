# Obsidian Lecture Pack

## 호출

```text
/obsidianpack
```

또는:

```text
옵시디언 강의팩 만들어줘.
```

## 권장 입력

- YouTube 링크
- SBV/SRT/VTT 자막
- NotebookLM 정리본
- 강의명·날짜·강사명
- 필요한 화면 캡처

YouTube URL이 없으면 클릭형 타임링크와 영상 임베드는 보류합니다.

## 검증 현황

현재 상태는 `stable draft`입니다.

실제 실행 기록과 `stable` 승격 조건은
[Validation Log](VALIDATION_LOG.md)에서 확인할 수 있습니다.
