# Case 001 — 기도 응답 설교 일반 강의

## 검증 대상

- 강의: 하나님은 왜 우리의 기도에 응답하실까요?
- 강의 유형: 일반 설명형·주제형 설교
- 검사 날짜: 2026-08-02
- 공개 범위: 강의 원문과 전체 결과물은 공개 저장소에 포함하지 않음

이 사례는 v1.2.0 생성물의 정적 검사와
v1.3.0 재생성 결과의 사용자 기능 확인을 구분해 기록한다.

## 1차 검사 — v1.2.0 생성물

대상 파일:

```text

```

검사 방식:

- ZIP 구조
- 파일 해시
- Markdown 내부 링크
- 북마크 초 계산
- 앵커 연속성 자동 검사

- AI 동기화팩 내부 파일: 14개

### 내부 링크 검사

- 초 계산: 통과

### 앵커 검사

시작 앵커:

- 총 4개
- 원문전사에서 연속 문자열로 확인: 4/4

끝 앵커:

- 총 4개
- 원문전사에서 연속 문자열로 확인: 1/4
- 실패: 3/4

실패한 3개는 발화 자체는 원문에 있으나,
서로 다른 시간 구간 사이의 시간 제목을 건너 결합되어
`01_원문전사.md` 안에서 하나의 연속 문자열로 검색되지 않았다.

따라서 기존 검사자료의
`주제별 끝 앵커: 원문에서 확인`이라는 판정은 지나치게 넓었다.

### 일반 강의 경계 검사

- 학생 관련 필드 혼입: 0개
- 학생 사례 폴더: 없음
- 사용자용 볼트의 개발·검사 문서 혼입: 0개

### AI 동기화팩 판정

v1.2.0 초기 결과물에는 AI 동기화팩이 기본 생성됐다.
내부에는 사용자 볼트 자료 대부분과 `01_원문전사.md`까지 포함됐다.

이는 v1.2.0 규칙에는 맞지만 일반 강의 한 편의 기본 결과물로는 과도했다.

v1.3.0 설계 결정:

- 단독 모드: AI 동기화팩 생성 안 함
- 누적 모드: 경량 AI 동기화팩만 생성
- 누적 동기화팩: 과거 원문전사 제외

## 2차 확인 — v1.3.0 재생성 결과

사용자는 같은 설교 자료를 v1.3.0으로 다시 생성하고
Obsidian에서 다음 기능을 직접 확인했다.

- `02_북마크.md`가 생성됨
- 북마크 시간 링크를 누르면 YouTube 해당 시점이 재생됨
- `03_최종노트.md`의 시간 링크도 YouTube 해당 시점으로 이동함
- 개념 노트가 생성됨
- 워크플로우 노트가 생성됨
- 과정목차·AI 허브·강의 인덱스가 생성됨
- 그래프 뷰에서 강의·개념·워크플로우 연결이 표시됨
- 개념의 지식 상태가 한 강의만으로 `standard`로 과장되지 않음
- 화면상 학생 사례 폴더가 생성되지 않음

### 2차 판정

- 단독 결과 ZIP에 `AI_동기화용/`이 없는지
- 모든 시작·끝 앵커가 원문에 연속 일치하는지
