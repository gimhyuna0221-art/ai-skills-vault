# Multimodal Video Learning

## Separate channels

SPEECH_TRACK
- transcript/captions
- timestamps
- verbal claims
- stated procedure
- caveats

VISUAL_TRACK
- representative frames / scene sheet
- UI state
- values/settings
- code
- tables
- click/action sequence
- visual-only warnings

DIRECT_MULTIMODAL_TRACK
- optional supported public-video analysis

## Promotion rule
Video-derived material becomes durable doctrine only after task-relevant verification and testing.

## Dependency rule
Check third-party dependencies before installation. Do not silently install yt-dlp, ffmpeg, Node packages, browser extensions or scripts without authority.

## Claim rule
Do not claim speed, universal YouTube support, permanent free access, or fixed limits unless current primary evidence supports it.
