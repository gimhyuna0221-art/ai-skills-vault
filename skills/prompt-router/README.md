# Prompt Router v2

사용자의 요청을 더 좋은 질문으로 바꾸고, 필요한 사고·검증·도구 모드를 자동 선택합니다.

## 대표 호출

```text
/autoprompt
내 요청을 실행 가능한 프롬프트로 바꿔줘.
```

```text
/autoroute
이 문제에 필요한 방식을 알아서 골라 해결해줘.
```

## 주요 모드

- 재작성: `/human`, `/rewrite`, `/summary`
- 이해: `/background`, `/eli5`, `/ladder`, `/decompose`
- 분석: `/compare`, `/priority`, `/risk`, `/diagnose`
- 실행: `/step`, `/plan`, `/roadmap`, `/sop`, `/todo`
- 검증: `/critique`, `/factcheck`, `/verify`, `/qa`, `/tests`
- 도구: `/research`, `/tooluse`
