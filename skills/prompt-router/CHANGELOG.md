# Changelog

## 2.1.1 — 2026-08-04

- 본문 제목과 메타데이터 버전을 `2.1.1`로 일치
- `/realthink`가 독설·공격적 말투로 변질되지 않도록 직설성과 무례함을 구분하는 규칙 추가
- `/politics`에 거짓말, 기만, 여론 조작, 제3자 악용, 고의적 정보 은폐 금지 규칙 추가
- 상대의 선택권·체면 보존과 책임 전가 금지 원칙 추가
- 법률·정책·계약·플랫폼 규칙에 의존하는 전략은 사실 검증을 선행하도록 규정
- `/research + /factcheck + /politics + /risk` 자동 조합 예시 추가
- Prompt Router README를 새 명령과 조합 기준에 맞게 갱신
- 저장소 루트 README의 Prompt Router 역할 설명 갱신

## 2.1.0 — 2026-08-03

- `/realthink` 추가: 듣기 좋은 포장보다 현실적인 최종 판단, 핵심 근거, 불확실성, 실행 행동을 직접 제시
- `/realthink`를 비공개 내부 사고과정 공개가 아닌 검토 가능한 최종 판단 모드로 명시
- `/politics` 추가: 이해관계, 권한, 비용 부담, 약속, 평판, 집단 신호와 1차·2차 파급효과 분석
- `/politics + /realthink` 조합 라우팅 추가
- 통제할 수 없는 결과를 사용자의 실패로 평가하지 않는 원칙 추가
- 손실 회수와 손실 확산 방지를 구분하는 현실 판단 규칙 추가
