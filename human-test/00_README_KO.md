## 목적

이번 테스트는 “FieldPilot이 시장조사 1등인가”를 증명하는 시험이 아니다.
사람이 최신 후보를 실제로 썼을 때 아래 다섯 가지가 성립하는지 먼저 깨뜨려 보는 1차 falsification pass다.

1. 짧고 평범하게 말해도 쓸 만한 조사까지 스스로 진행하는가.
2. 좋은 기존 자료/전문자료를 찾아 활용하고, 읽지 못한 자료를 읽은 척하지 않는가.
3. 사용자의 목적에 맞는 판단과 다음 행동을 주는가.
4. 본격 조사에서는 추가 요청 없이 실제 보고서 파일까지 전달하는가.
5. 사용 부담이 과하지 않은가.

## 사람 구성

권장 3–4명. 통계적 유효성을 주장하기 위한 표본이 아니다.

- 가능하면 이전 FieldPilot을 써 본 사람 1명: 회귀/개선 체감 확인.
- FieldPilot을 처음 쓰는 사람 2명 이상: 온보딩·차별성 확인.
- 가능하면 실제로 AI로 조사/기획/개발하는 사람 1명 이상.

동일한 사람이 개발자/AI사용자 등 여러 조건에 해당해도 된다.

## 테스트 순서

각 테스터는 새 채팅/새 세션에서 실행한다.

1. 고정 과제 A
2. 설문 중간 기록
3. 실제 과제 B
4. 최종 설문

진행자는 답을 도와주지 않는다. AI가 불필요한 질문을 하면 그대로 기록한다.
로그인·결제·Cookie·회사 기밀·개인정보를 요구하는 실험은 이번 1차 테스트에서 하지 않는다.

## 기록해야 할 것

- 사용한 호스트/모델/effort
- 시작/종료 시각
- 유용한 첫 결과까지의 turn 수
- 전체 turn 수
- AI가 먼저 한 추가 질문 수
- 파일 산출물 실제 제공 여부
- 클릭/열람/행동으로 이어진 출처·경쟁사·자료
- 잘못된 사실/출처/과장 여부
- 사용량 표시가 있다면 시작/종료 수치. 없으면 UNKNOWN
- 참가자의 자유 피드백

## 금지 해석

- 3–4명의 만족을 PMF, 시장수요, 일반적 우월성으로 부르지 않는다.

- 참가자가 칭찬한 사실과 실제 행동(링크 열람, 의사결정 변경, 재사용)을 구분한다.
- 한 회사/한 프로젝트에서 잘했다고 모든 시장조사에 일반화하지 않는다.
