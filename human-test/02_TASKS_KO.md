# Human Pilot 01 — Tasks

## TASK A — 공통 고정 과제

아래 문장을 그대로 사용한다.

> /fieldpilot  
> 두산로보틱스를 시장조사해줘. 목적은 이 회사와 사업 미팅을 하기 전에 회사가 뭘 하고, 시장이 어떻게 움직이고, 경쟁사는 누구고, 최근에 중요한 변화와 위험이 뭔지 빠르게 이해하는 거야. 공개자료만으로 알기 어려운 걸 현직자에게 물어볼 질문도 8개 만들어줘. 최종 보고서 파일도 줘.

### TASK A가 보는 것

- 평범한 표현으로도 full/professional research로 들어가는가.
- 제품개발/판매 상담으로 잘못 라우팅하지 않는가.
- 회사 공식자료, 산업/경쟁 자료, 전문자료를 역할에 맞게 고르는가.
- 최신성·반대근거·미확인 사항을 구분하는가.
- 현직자 질문이 공개자료를 되묻는 수준을 넘는가.
- 파일을 다시 요청하지 않아도 실제 보고서 artifact가 나오는가.

### 진행자 개입

원칙적으로 없음.

AI가 “어떤 목적이냐”처럼 이미 제공된 정보를 다시 묻는 경우 그대로 답하지 말고,
**“위에 적은 목적 그대로야. 알아서 진행해줘.”**라고 한 번만 말한다.
그 이후 반복 질문은 facilitator rescue로 기록한다.

## TASK B — 참가자의 실제 과제

참가자가 현재 실제로 궁금한 것 하나를 선택한다.

허용 예:
- 만들고 있는 앱/게임/서비스의 경쟁사와 시장
- 회사/산업 조사
- 가격·유통·판매 경로 조사
- 이미 출시한 서비스가 왜 반응이 없는지 조사
- 다음에 무엇을 만들거나 보류할지 판단

입력은 평소 AI에게 말하듯 작성한다. 연구용 전문용어를 일부러 넣지 않는다.

### 제외

- 회사 내부 비공개 자료
- 실제 고객 개인정보
- 계정 비밀번호/Cookie
- 결제/유료 서비스 구매가 필요한 과제
- 법률·의료 등 고위험 전문판단을 주목적으로 하는 과제

### TASK B가 보는 것

- 실제 자기 문제에서 결과가 행동으로 이어지는가.
- 평범한 AI와 다른 가치가 느껴지는가.
- 중요한 경쟁사/대안/출처를 새로 발견하는가.
- 결과가 길기만 한지, 실제 판단을 도와주는지.
- 재사용 의향이 생기는가.
